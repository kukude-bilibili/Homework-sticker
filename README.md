## 作业贴纸
用于将学生证照片覆盖到作业截图上,用于交作业的便捷工具,特别是交的数量一次性特别多的时候
### 使用说明
一、准备工作
------------
1. 确保电脑已安装 Python
   - 如果没有安装，请从 https://www.python.org/downloads/ 下载并安装
   - 安装时请勾选 "Add Python to PATH"

2. 安装 Pillow 图像处理库
   - 打开命令提示符 (CMD) 或 PowerShell
   - 输入: pip install pillow

二、使用方法一：批量贴纸（推荐）
-------------------------------
1. 双击运行 "批量贴纸.bat"
2. 第一次运行会自动创建三个文件夹：
   - main/            - 放入贴纸图片(你的学生证)
   - needed_picture/ - 放入需要添加贴纸的图片(你的作业截图)
   - finish_picture/ - 处理后的图片会保存到这里
3. 把贴纸图片(eg.学生证照片)放入 main 文件夹
4. 把需要添加贴纸的图片(eg.作业截图)放入 needed_picture 文件夹
5. 再次双击 "批量贴纸.bat"
6. 处理完成！

三、贴纸位置
------------
- 贴纸会自动添加到每张图片的左下角
- 贴纸大小会自动调整为图片宽度的 20%
- 贴纸距离边缘 20 像素

四、支持的图片格式
------------------
- PNG (推荐，支持透明背景)
- JPG / JPEG
- BMP
- GIF

五、文件说明
------------
- 批量贴纸.bat     - 批量贴纸（推荐使用）
- 批量贴纸.py      - 批量贴纸脚本
- 使用说明.txt     - 本文件
